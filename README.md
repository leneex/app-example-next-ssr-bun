# Next.js SSR на Bun

Пример приложения [Next.js](https://nextjs.org/) на [Bun](https://bun.sh/) с серверным рендерингом (SSR).

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `3000` |
| Путь проверки состояния | `/` |

Railpack видит `bun.lock`: ставит зависимости через Bun, собирает проект (`bun run build`) и
запускает сервер Next.js (`bun run start`). Страница отрисовывается на сервере при каждом запросе.
Сервер слушает `0.0.0.0` и порт из переменной окружения `PORT` — её передаёт платформа, — а без
неё `3000`.

Статическая версия — `app-example-next-bun`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
bun install

# запуск в режиме разработки
bun run dev

# сборка для продакшн
bun run build

# запуск собранного серверного приложения
bun run start
```
